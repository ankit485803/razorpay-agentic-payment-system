

# Razorpay Agentic Payment System

An AI-powered payment agent designed for **AI-driven growth and agentic commerce**.

## Features

- 🤖 AI-powered payment assistant
- 💬 Natural-language payment requests
- 💳 Razorpay payment integration
- 🔎 Transaction lookup
- 🔗 Payment-link generation
- 🔐 Secure payment confirmation

## Tech Stack

- Frontend: React (MERN)
- Backend: Node.js, Express (ES Modules)
- AI Agent: Anthropic Claude (tool calling)
- Payments: Razorpay Test Mode APIs

## Setup

```bash
git clone <YOUR_REPOSITORY_URL>
cd razorpay-agentic-payment-system
npm install
npm run dev
